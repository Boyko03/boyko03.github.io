A tool for creating a visual script based on a node graph, and then generating a Lua script from it. Made for the BEE custom engine.

Project Overview

Visual scripting or visual programming is a form of programming that lets the user create programs by using graphical elements instead of writing traditional code. This makes it easier to use by non-programmers, as they don’t have to learn a specific language, and allows for faster prototyping by designers.

I made a tool for creating a visual script based on a node graph, and then generating a Lua script from it.

The Challenge

I wanted to make a tool that would allow designers to quickly and easily write custom behaviors and be able to iterate quickly. The tool also had to be able to easily integrate with the existing engine. Objects in the game had to be able to interact with each other, which meant that scripts had to support various events and had to be able to access variables and functions from other scripts.

The Solution

After researching the topic, I decided to use Lua because of its fast execution. When the user presses the "Compile" button, a Lua script is generated from the node graph. The script is then compiled which means that the graph is processed only once while in-editor and during runtime the program is using the precompiled scripts.

The engine was using an Entity Component System (ECS) which made using Unity's ECS approach easier to implement than Unreal's blueprints so I made it that scripts can be attached to objects as components. This allows for quick iterations as the users can edit the script and reload it at runtime.

The user can define functions with arguments and return values of different types, implement events, declare variables of different types, and for optimization reasons declare local variables for each function and event in the script.

I added nodes for interacting with the ECS for getting, adding, and removing components, as well as checking if an entity has a specific script. If it does, functions and variables from that script can be accessed.
