Dynamic Voronoi Split Screen made in Unreal Engine 5

Project Overview

This is one of the projects that taught me how important research is when you are not familiar with the topic. I did it as part of my self-study project where I wanted to learn how local and online multiplayer work in Unreal Engine 5.

The Challenge

I decided to start with the local multiplayer because it's easier. While researching the different split screen options and how I can enable and disable it at runtime, one of my teachers suggested me to look at the split screen in the Lego game and to try and make it in Unreal.

I had no previous experience on this topic so I started researching...

The Solution

At first, I started looking at Unreal's source code to see how it is implemented there and I even added new settings to the "Project Settings" (for which I had to compile the engine from source). Unfortunately, the way it is done in Unreal allows only for rectangular windows and not Voronoi ones like in the Lego game.

After doing some more research, I found several plugins for dynamic split screen and different examples of how it can be implemented (there was even a Godot example that runs in the browser which helped me a lot in defining what I want the end result to look like).

The simplest solution is the best solution. In the end I just replaced the CameraComponent of the player with a ScreenCaptureComponent which I offset based on the distance between the players and the direction to them. Then I used a Post Processing Material to blend the two textures and that's it!

After that, I made it to be a plugin so that I can use it in my other projects if I need it. It works for top-down games or games where the camera rotation is fixed.

It currently works only with two players, but I'm planning to continue developing it and adding support for N players.

Project Features

  • Dynamic Voronoi Split Screen
  • Simple and easy to use
  • Customizable
